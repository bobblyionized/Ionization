                                About

                                Ionization, a visual changer for Windows 11

                                Updates

                                v0.0.0current

                                Ionization checks GitHub for new builds on launch and every six hours, verifies the download, and restarts itself in under a second.

                                How it works

                                Every refresh, the desktop is captured on the GPU with Desktop Duplication, blended with previous frames in linear light, graded, and presented in a click-through layer that is excluded from its own capture, so there is no feedback loop.
